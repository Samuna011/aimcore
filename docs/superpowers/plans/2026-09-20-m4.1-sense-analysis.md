# M4.1 sense-analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `sense-analysis` crate — deterministic reconstruct → hybrid segment → BehaviorMetrics + ExposureMetrics for STATIC_CLICK/GRIDSHOT from persisted telemetry only (`analysis_version` `"1"`).

**Architecture:** New workspace crate depends on `sense-telemetry` + `sense-types` (+ `sense-accel` only for Linear scale oracle in quality). Extend telemetry load to include `aim_input_samples`. No Bevy, no DB writes, no attribution/UI.

**Tech Stack:** Rust 2021 workspace, rusqlite via sense-telemetry, serde_json, sense-accel for scale recompute.

**Spec:** `docs/superpowers/specs/2026-09-20-m4.1-sense-analysis-design.md`

## Global Constraints

- `analysis_version = "1"`; never silently retune constants
- onset 40 / settle 15 / settle_ms 80 / min_movement_ms 40 / shot_attach_ms 150 / post_click_max_ms 300 / gap_ms 50 / jitter_window_ms 40 / scale_mismatch_eps 1e-3 absolute
- STATIC_CLICK + GRIDSHOT only; TRACKING → `UnsupportedTrialType`
- Behavior vs Exposure namespaces only — no `cause` / recommendations
- Hit/miss must not affect segmentation
- Ephemeral `AnalysisResult` + JSON dump example; no DB write; no public CLI
- No app `EXPERIMENT_VERSION` bump
- Defer commits until user asks (session preference)

```rust
pub struct ReconstructedTrial {
    pub camera: Vec<CameraPoint>, // t_ns, yaw, pitch, angular_speed_deg_s
```
