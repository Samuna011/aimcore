# TRACKING v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship TRACKING v1 — one horizontally strafing sphere with random sudden reversals; score = time on target while LMB held; full look telemetry; Lobby + pause + History; experiment `0.12.0`.

**Architecture:** New `aim_tracking.rs` pure motion/score helpers + runtime on `AimTrial`. Sample-discrete scoring in the mouse drain path. `direction_change` events for every reverse/wall bounce. Extend History replay to integrate velocity between events. No schema change; no `aim_shots` for TRACKING.

**Tech Stack:** Bevy 0.19, existing aim/Lab UI/History stack, sense-math ray–sphere.

**Spec:** `docs/superpowers/specs/2026-09-20-tracking-v1-design.md`

## Global Constraints

- Duration **30.0 s** active (pause-excluded); R=**0.25**; z=**−6**; y=**1.6**; x ∈ **[−1.5, 1.5]**; \|vx\|=**1.2**; reverse delay **U(1.5, 3.5) s**
- Score only when **LMB held ∧ ray hits**; look/input/camera always logged
- Log `direction_change` on RNG reverse **and** wall bounce; no re-roll in History
- No `aim_shots` for TRACKING v1; `hits`/`shots`/`misses` = 0; `score_secs` = on-target seconds; `accuracy` = score/active_duration
- `trial_type = TRACKING`, `task_version = "1"`
- `EXPERIMENT_VERSION` / `AIM_EXPERIMENT_VERSION` → **`0.12.0`** in final task only
- Do not break STATIC_CLICK / GRIDSHOT / Lab UI / History for existing types
- No schema changes; no 1wall6 / vertical motion

}

// score_secs = time_on_target_ns/1e9; accuracy = score/active; hits=shots=0; despawn; Idle

Per sample order (when Playing / not paused):
1. If `tracking_should_end` → finish + persist; skip further gameplay on this sample.
2. Else update LMB held from buttons.
3. Else `dt_s = dt_ns/1e9`; `step_strafe`; if wall bounce or `now >= next_reverse_at` → reverse, emit `direction_change`, reschedule reverse.
4. Update live target center; if held+hit → add `on_target_dt_ns`.
5. Push input/camera samples as today (always).

`build_completed_aim_trial_record` / accuracy: for Tracking use `time_on_target` based accuracy (override shot-based formula when `task_kind == Tracking`).

**Replay integration algorithm:**
```text
Walk events with timestamp <= t in order.
spawn/direction_change: set id→(pos, vel); update pos to event position; set vel from event.
despawn: remove id.
After applying all events <= t, for each live id:
  integrate pos.x += vel.x * ((t - last_event_ts_for_id) / 1e9)
  (y,z fixed)
```
Store `last_event_ts` per id while walking. Wall bounces are already events — do not re-bounce in replay.

HUD Playing: `TRACKING · on-target {score:.2}s · {acc:.0}% · left {rem:.1}s` (+ “hold LMB” hint).
