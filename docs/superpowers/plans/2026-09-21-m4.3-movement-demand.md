- [ ] **Step 2: Implement `demand.rs`**

```rust
#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct MovementDemand {
    pub angular_displacement_deg: f64,
    pub target_distance_deg: Option<f64>,
    pub commanded_yaw_deg: Option<f64>,
    pub peak_physical_input_speed: Option<f64>,
    pub movement_duration_ms: f64,
}

#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct ProcessorExposure {
    pub peak_processed_speed: Option<f64>,
    pub peak_accel_scale: Option<f64>,
}
```

Compute displacement from acquisition camera path (start→end √(Δyaw²+Δpitch²) or path endpoints); `target_distance_deg` from onset aim to target dir; `commanded_yaw_deg` from matching spawn `event_data_json` / `yaw_deg`; physical peak from input points on window using physical_* speeds; duration from behavior window. Exposure from processed physical peak + stored scale peak — never fold into MovementDemand.
