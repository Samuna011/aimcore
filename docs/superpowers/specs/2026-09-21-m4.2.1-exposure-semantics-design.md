# M4.2.1 — Exposure Metric Semantics (Physical vs Processor)

**Date:** 2026-09-21  
**Status:** Implemented  
**Depends on:** M4.1 / M4.2 (`compare_trials`)  
**analysis_version:** `"2"` (ExposureMetrics rename + physical÷`dt_ns`; segmentation knobs unchanged)  

## Goal

Make NoAccel vs RawAccel exposure **comparable** by separating physical QPC speeds from processor speed-path quantities. Do **not** change Raw Accel, persisted `input_speed`, or `dt_used_ns` semantics.

## Root cause

`reconstruct_inputs` derived “raw_speed” as `mag / dt_used_ms`. For `none`, `dt_used_ns == dt_ns` (unclamped QPC). For `rawaccel_linear`, `dt_used_ns` is RA clamp → stored `input_speed` units. Same motion looked ~70× different in M4.2 tables.

## Analysis-layer only

```text
raw telemetry (unchanged)
    ↓
reconstruct_inputs
    ├── physical_*_speed  → mag / (dt_ns → ms)
    └── processor_input_speed → Option(stored input_speed)  // never invent for none
```

## ExposureMetrics (`analysis_version` `"2"`)

| Field | Meaning |
|-------|---------|
| `physical_raw_speed_{mean,peak}` | √(dx²+dy²) / dt_ns_ms |
| `physical_processed_speed_{mean,peak}` | √(pdx²+pdy²) / dt_ns_ms |
| `processor_input_speed_{mean,peak}` | `Option` — mean/peak of **stored** `input_speed` only |
| `acceleration_scale_{mean,peak}` | stored scale (`None` if absent) |
| `cap_exposure` / `cap_applicable` | unchanged |
| `gain_ratio_*` | mag(processed)/mag(raw) per sample (unchanged) |

### Per processor

| | none | rawaccel_linear |
|--|------|-----------------|
| physical_* | available | available |
| processor_input_speed | **null** | stored `input_speed` |
| acceleration_scale | **null** | available |

Do **not** recompute processor_input_speed for NoAccel to fill the table.

## Non-goals

- Changing `sense-accel` / Raw Accel
- Rewriting DB rows or `aim_input_samples.input_speed`
- M4.3 attribution
- Multi-run pooling API

## Acceptance

- On matched GRIDSHOT none vs linear: physical raw means within the same order of magnitude
- none → `processor_input_speed_*` is `None`; linear → Some ≈ stored mean
- Segmentation freeze tests still pass (knobs unchanged)
- Docs + compare deltas use new names
